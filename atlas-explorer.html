Atlas Explorer

A satellite globe for young learners. Click any country or city to see its basics, what its people call themselves, common customs, and the local time and weather.

Open Atlas ExplorerView the code on GitHub
Background
It started as a quick Claude Design experiment that told a story about any region you clicked. I rebuilt it as a globe I could keep improving.
Hypothesis
Children remember a place better when they see its people and customs next to its map, instead of a list of facts.
Key decision
Facts are stored inside the page, so it loads fast and works offline. Only the weather is fetched live.
Implementation
Plain HTML and JavaScript on GitHub Pages. D3 draws the globe; NASA imagery is redrawn on a canvas with a real-time day/night shadow and the sun and moon positions. Weather from Open-Meteo.
Testing and validation
Browser checks on laptop and phone sizes, search tests for typos, local names and filters, and a check that borders line up with the satellite image.
Next steps
Planned: live population figures from the World Bank, culture notes for more countries, and a plain-English “ask the globe” question box.

Product decisions and trade-offs

Data source

No API key on a public page

REST Countries moved behind an API key, and a key on a public page can be copied, so country facts are stored in the page instead.

Clutter

Cities appear as you zoom in

947 city pins hid the countries. Country names now come first, and cities appear by size as you zoom in.

Brand

One mode, characters in the gaps

Built in my design system’s Pro Dark mode. Characters appear only while loading, on empty searches and at night.
