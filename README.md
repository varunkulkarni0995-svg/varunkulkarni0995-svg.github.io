# varunkulkarni0995-svg.github.io

Personal website of Varun Kulkarni. Plain HTML on GitHub Pages; styles from the VK design system (Pro theme).

- Pages: `index.html`, `layer-up.html`, `about.html`, `404.html`
- Styles: `css/vk-pro.css` (design tokens), `css/bundle.css` (VK components), `css/site.css` (site-only)
- `tools/build_from_design.py` turns the design canvas files into these pages
- Tools live at `/layer-up/` and `/api-bench/` from their own repositories
